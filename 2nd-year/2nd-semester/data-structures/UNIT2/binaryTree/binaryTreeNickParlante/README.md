# Práctica: Árboles binarios y recursión

Proyecto base para la práctica de Estructuras de Datos.

Material de referencia:

Nick Parlante, *Binary Trees*, Stanford CS Education Library,
Document #110, 2000–2001.

http://cslibrary.stanford.edu/110/

## Compilación

```bash
make
./trees
```

## Archivos

- `include/tree.h`: tipo `Node` y operaciones básicas del árbol.
- `src/tree.c`: `newNode`, `insert` y `freeTree`.
- `include/tree_algorithms.h`: firmas de los ejercicios.
- `src/tree_algorithms.c`: implementaciones pendientes.
- `src/main.c`: programa mínimo para construir un árbol y probar funciones.

Las implementaciones iniciales de `tree_algorithms.c` son solo esqueletos para
permitir que el proyecto compile. Deben ser reemplazadas durante la práctica.
