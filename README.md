## Cursos por año

### 2do Año

#### 3er Ciclo (1er semestre)

**Arquitectura de Computadoras**

Trabajo práctico con **emu8086**. Se desarrolló el juego *OPM-Reflex* como proyecto integrador, aplicando manejo de interrupciones, entrada/salida de datos y lógica de control a bajo nivel.

**Programación**

Avance en el lenguaje **C**, abarcando desde estructuras básicas hasta conceptos clave como **punteros** y **recursión**. También se exploraron algoritmos de ordenamiento, estructuras de datos y gráficos con Turtle.
