# Árbol rojinegro C++11 (iterativo)

`red_black_tree.hpp` y `red_black_tree.cpp` definen `red_black::RedBlackTree`.
La búsqueda, el descenso de inserción y las reparaciones usan bucles; el árbol
se libera automáticamente al destruir la instancia. `main.cpp` contiene las
pruebas.

Desde el directorio padre: `make test-cpp` o `make sanitize-cpp`.
